# WinTraceForge documentation

WinTraceForge investigates path-dependent security visibility by comparing observable evidence for the same operation or equivalent outcome through different Windows implementation paths. These guides cover the current Defender Antivirus, ASR, and Windows Firewall experiments and their existing control lifecycle.

Choose a guide based on what you need to do:

| Audience | Start here | Covers |
| --- | --- | --- |
| Users and test operators | [User docs](user/README.md) | Install, choose commands, collect evidence, interpret results, and clean up tests. |
| Developers and maintainers | [Developer docs](dev/README.md) | Understand current experiments, transport and evidence contracts, build, validate, and release. |

The [repository README](../README.md) provides the project introduction and quick start. [CHANGELOG](../CHANGELOG.md) records release history; [SECURITY](../SECURITY.md) describes vulnerability reporting.

These guides describe the source in this checkout. When using a released binary, consult the documentation bundled with that release; unreleased commands and transports may differ.
